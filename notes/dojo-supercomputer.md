# Tesla Dojo 超级计算机技术详解

> **版本**: 1.0 | **更新**: 2026-03-22

---

## 🎯 什么是 Dojo？

Dojo 是 Tesla 自研的超级计算机，专门用于训练自动驾驶神经网络。

---

## 🏗️ 技术架构

### **D1 芯片**

| 规格 | 数值 |
|------|------|
| **制程** | 7nm |
| **晶体管** | 362亿 |
| **算力** | 362 TFLOPS |
| **功耗** | 400W |
| **封装** | 25D |

### **训练瓦片 (Training Tile)**

```
一个训练瓦片 = 25个D1芯片
    ↓
算力: 9 PFLOPS
    ↓
互联带宽: 36 TB/s
```

### **ExaPOD**

```
一个ExaPOD = 120个训练瓦片
    ↓
总算力: 1.06 EFLOPS
    ↓
相当于: 6个顶级超算
```

---

## 🚀 核心优势

### **1. 专用设计**
- 专为神经网络训练优化
- 高效的数据流水线
- 低延迟互联

### **2. 成本效益**
- 比通用GPU成本低
- 能效比高
- 定制化优势

### **3. 扩展性**
- 模块化设计
- 易于扩展
- 线性性能增长

## 📈 发展路线

### **2021**: Dojo 发布
- D1 芯片亮相
- 架构公开

- 内部测试
- 性能验证

### **2023**: 大规模部署
- 多个 ExaPOD 上线
- 训练效率提升

- D2 芯片研发
- 性能翻倍
